# 四阶段 prompt 模板

这些模板是给代理作为“教练”使用时的生成规范。执行时只加载当前阶段的模板，不要把后续阶段的答案提前生成。

## Phase 1：骨架提取

学生先完成 `student/attempts/phase1.md`，内容至少包含：

1. 学生目前认为该领域的 3-5 个核心心智模型。
2. 学生目前认为最重要的争议或未知问题。
3. 用不超过三层结构写出的个人知识骨架初稿。

学生尝试非空后，教练再生成以下内容：

```text
你是一位跨学科知识架构师。基于材料包，提取该领域的可验证知识骨架。

1. 【心智模型提取】
   给出 3-5 个核心心智模型。每个模型：
   - 用一句话定义；
   - 说明它解决哪类问题；
   - 标注哪些材料支持、哪些材料修正或挑战它；
   - 用其他成熟学科的类比解释本质。

2. 【争议地图构建】
   给出 2-3 个根本争议。每个争议：
   - 指出底层假设差异，而不是表面观点差异；
   - 列出各方最强的两个论据；
   - 区分已解决共识、活跃争议、开放问题；
   - 指出对未来 5 年发展方向的影响。

3. 【知识骨架输出】
   用不超过三层输出完整骨架：
   - 第一层：核心范式/世界观；
   - 第二层：支撑范式的关键理论/方法；
   - 第三层：典型技术/工具/案例。
   每个节点标注承重属性：移除它是否会导致结构崩塌？
```

输出保存到 `coach/phase-artifacts/phase1.md`，再按协议解锁。

## Phase 2：认知压力测试

只生成题目，不生成标准答案。题目写入 `shared/questions/{id}.md`，并使用 `start-question` 登记。

```text
基于 Phase 1 的知识骨架和争议地图，生成 10 道“区分题”。

要求：
- 死记硬背者无法回答，真正理解者可以；
- 每道题跨越至少两个心智模型，或连接共识区与争议区；
- 题型分布：4 个概念辨析、3 个场景应用、2 个方法论比较、1 个开放设计；
- 每题附带一个看似合理但错误的陷阱选项，但不要在题目中说明哪一个是陷阱。

只输出题目本身、场景和作答格式说明，不输出答案、判断或推理。
```

学生提交 `student/answers/{id}.md` 后，教练再生成 `coach/feedback/{id}.md`：

```text
你是严格的资格考试考官。学生已经提交答案，请按以下格式反馈：

1. 【判断】正确 / 部分正确 / 错误
2. 【逻辑漏洞定位】指出推理链条中最薄弱的环节，而不是只说答案错。
3. 【遗漏的关键逻辑】指出被遗漏的概念、假设或边界条件。
4. 【追问】基于错误生成一个更深入的追问，迫使学生换角度重想。
5. 【修正后的完整推理】不直接给答案，给出修正后的推理路径，让学生自己推出正确结论。

在学生对追问作出新的回答前，不要进入下一题。
```

## Phase 3：边界探索与迁移验证

学生先写 `student/attempts/phase3.md`，至少完成：

1. 对某个核心心智模型做反事实推演。
2. 给出一个相邻领域的方法误用案例，指出根源、正确迁移方式和风险。
3. 用不超过 400 字向非专业人士解释该领域价值。
4. 从开放问题中提出两个可动手验证的小问题。

教练再生成 `coach/phase-artifacts/phase3.md`，检查：

```text
检查学生的边界探索是否满足迁移标准：
- 反事实推演的因果链条是否完整；
- 误用案例是否真的区分了适用条件和泛化边界；
- 最小可行解释是否能让听众据此作出一个合理决策；
- 未知问题是否能在现有材料基础上通过简单实验、推导或文献追踪验证。

只指出推理断裂和遗漏，不代写结论。
```

## Phase 4：个人知识资产固化

学生先写 `student/attempts/phase4.md`，包含个人概念图、错题分类、速查卡初稿。教练再生成 `coach/phase-artifacts/phase4.md`，对学生的资产做补漏和校对。

```text
综合前面所有阶段，帮助学生固化知识资产：

1. 【个人概念图】用 Mermaid 或文本层级结构输出，标注绿/黄/红掌握程度。
2. 【错题本】按概念混淆、边界盲区、推理断裂、假设误植分类，每类附一个典型错误和修正思路。
3. 【速查卡】生成 5 张不超过 100 字的卡片，覆盖领域差异、决策前提、认知陷阱、开放问题和唯一核心洞察。

只补学生遗漏的内容，并保留学生已经正确写出的部分。
```

最后使用 `finish-phase` 和 `export` 固化成果。
